Four modes, one skill

routed by intent — no commands to remember
01

Homework guide

You giveAn assignment — PDF, screenshot, or DOCX
It doesSplits it into 3–8 steps, explains only the current step, checks the screenshot you send back, and refuses to spoil later steps
You getA submittable report built from evidence you actually produced
> Here's my lab assignment, walk me through it
02

Quiz grading

You giveA problem set, then short messages like 2.3 12 C
It doesIndexes every question first, grades each answer independently, 2–3 sentences when right, real error analysis when wrong
You getA mistake notebook — short enough to re-read the night before
> 2.3 12 C (one question per line, no essays back)
03

Knowledge breakdown

You giveA topic you don't really understand yet
It doesBuilds a dependency tree of foundational layers, then teaches one layer per turn with a mini-check before advancing
You getA full-tree cheat sheet plus a one-page reference table
> Break down virtual memory for me
04

Review & mock test

You giveSlides, lecture notes, past papers
It doesInventories the material and names what's missing, builds a knowledge skeleton, or issues mock tests with answers kept separate
You getSummary doc, score breakdown, targeted review plan
> Here are all the slides — review me, then quiz me
