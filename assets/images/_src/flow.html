Progress doesn't get lost between sessions

Records are read at the start of a session and appended at the end of a cycle — never once per question
01 · START

Read the progress file

Picks up progress/<course>.md and states where you stopped. You never re-explain your own progress.

→
02 · WORK

One unit at a time

One step, one question, or one layer — confirmed before moving on.

→
03 · CYCLE ENDS

Append the facts

Date, item, result, note. Incremental edits only — your own writing is never overwritten.

→
04 · NORMALIZE

CRLF → LF

Byte-level rewrite first. The pusher uploads raw working-tree bytes, so skipping this writes CRLF into the remote.

→
05 · SYNC

Save it

Stays in a local folder, or also pushes to your own private repo over the REST API.
